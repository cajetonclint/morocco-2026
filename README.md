# Our Morocco Trip website

## Publish free with GitHub Pages
1. Create a GitHub repository (for example `morocco-trip`).
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. GitHub will provide the public website address.

## Update later
Edit `index.html`, commit/push the change, and GitHub Pages will redeploy it.

## Privacy
This page includes travel dates, accommodation addresses, booking confirmation numbers and a guide contact number. A normal public GitHub Pages site can be viewed by anyone who has or discovers the URL.
